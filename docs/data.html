Data

This analysis uses only publicly available data. No proprietary correspondent-banking or SWIFT data was used. All sources, vintages, and processing scripts are documented in the replication package.

Limitations and disclosure

This is a preliminary analysis using publicly available data. Three caveats:

  1. The de-risking measure is a proxy. We do not observe correspondent-banking account closures directly; we use bilateral FDI collapses as a stand-in. Direct CBR data from the BIS Statistics on Correspondent Banking or SWIFT would sharpen the test.
  2. Heaviest specifications run on a subsample. The full bilateral × product × year panel exceeds the memory available under a four-fixed-effect Poisson estimator. A 3,000-pair stratified subsample is used for the most demanding specifications; the main results are robust to this restriction (see the paper’s robustness section).
  3. Infrastructure axis is a placeholder. GDP per capita / internet penetration is a coarse stand-in for where stablecoin infrastructure actually exists. The Chainalysis Global Crypto Adoption Index would be a direct replacement.
